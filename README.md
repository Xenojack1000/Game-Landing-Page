## Overview

A comprehensive web platform for distributing educational games that promote "stealth learning" - integrating educational content into games to make learning more engaging and enjoyable. This project bridges the gap between entertainment and education by providing a platform for game developers to distribute their stealth learning games while offering gamers an opportunity to enhance their knowledge and skills in a fun, interactive way.

### Key Features

- **Game Catalog** - Browse and purchase educational games with detailed information pages
- **User Authentication** - Secure registration, login, and profile management system
- **Shopping Cart** - Interactive cart functionality with real-time price calculation
- **Community Forum** - Discussion threads and comment system for user engagement
- **Review System** - Rate and review games with CRUD operations
- **Admin Panel** - Complete content management system for games and carousel
- **Responsive Design** - Mobile-friendly interface with Bootstrap framework

### Tech Stack

- **Frontend**: HTML5, CSS3, JavaScript, Bootstrap, Font Awesome
- **Backend**: PHP, MySQL
- **Security**: SSL/TLS encryption, input validation, access control
- **Tools**: W3C Validator, Axe DevTools for accessibility testing
